# Hoja de decisiones · reunión única del equipo

**Preparada:** 2026-10-09 por Claude Code, a pedido del equipo, a partir de `DECISIONES.md`, `REGLAS-DE-NEGOCIO-FORMALIZADAS-TecnicoYa.md` (§2, §3, §9), `CANVAS-Analisis-MVP-TecnicoYa.md` (§18, pendientes P01 a P23), `analisis-estado/CONTEXTO-COMPLETO-2026-10-09.md` (§2.c y §3.2) y la adenda P10.

**Qué es y qué no es:**
- Es una hoja de trabajo para decidir. **Nada de lo escrito aquí está decidido.** Las recomendaciones son de Claude Code y la columna «Decisión del equipo» está vacía a propósito.
- La «propuesta actual» sale de las fuentes; si dice «sin valor», las fuentes no traen ninguno.
- **No hay valores de mercado.** Esta hoja no fija tarifas, montos, distancias en kilómetros ni duraciones de servicio. Donde la regla necesita un número de ese tipo, las opciones son de método (cómo se obtiene el número), no el número.
- Los límites de producto que sí aparecen como opción (longitudes de texto, tamaño de archivos, cantidad de solicitudes) **no salen de ninguna fuente**: se marcan «sin fuente» y solo valen si el equipo los aprueba.

**Cómo usarla en la reunión:**
1. Recorrer los bloques en orden. El bloque 1 es lo mínimo para cerrar S1 a S3.
2. En cada fila, escribir la opción elegida (letra o texto) en «Decisión del equipo».
3. Al terminar, Claude Code pasa cada fila decidida a «Decisiones tomadas» de `DECISIONES.md` con la fecha y quién decidió (regla 10 de AGENTS.md). Esta hoja no reemplaza a `DECISIONES.md`.
